Developer & Admin Utility

GitHub Repository & Deployment Guide

Follow these exact instructions to host this website live using GitHub Pages for free.

Step 01

Create GitHub Repository

Log into GitHub.com, click "New Repository", name it vinocent-global-resources, set it to Public, and click Create.

Step 02

Save HTML File

Save all this web code into a file named index.html inside your local project folder.

Step 03

Enable GitHub Pages

In your repo settings, navigate to Pages, select branch main (or master), and click Save.

Terminal / Git Bash Commands

# 1. Initialize local repository

git init

# 2. Add files and make initial commit

git add index.html

git commit -m "Initial commit: Vinocent Global Resources website"

# 3. Rename default branch to main

git branch -M main

# 4. Link your GitHub remote URL (replace YOUR_USERNAME)

git remote add origin https://github.com/YOUR_USERNAME/vinocent-global-resources.git

# 5. Push code live!

git push -u origin main

Live URL Pattern: https://<username>.github.io/vinocent-global-resources/
